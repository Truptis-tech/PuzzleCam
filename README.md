PuzzleCam 🧩📸

PuzzleCam is a beginner-friendly frontend mini-project focused on interactive puzzle solving. It explores how camera-based puzzle capture and automated solving can make puzzles more engaging.

✨ Project Overview

The goal of PuzzleCam is to create an interactive puzzle-solving experience where a puzzle can be captured using a camera and solved through an automated process, with the possibility of integrating a physical robot.

🚀 Features

- Interactive puzzle-solving interface
- Visual puzzle pieces and swapping functionality
- Automated solving logic and step-by-step animations
- A foundation for future camera integration and robotic automation

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

▶️ How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" in your browser, or use the Live Server extension.
4. Explore the available puzzle features.

🎯 Project Objective

This project helps develop practical frontend development skills and explores the foundations of interactive puzzle-solving applications.

🔮 Future Improvements

- Integrate camera access to capture puzzle images.
- Explore computer vision to identify puzzle pieces.
- Improve the puzzle-solving algorithm.
- Integrate a physical robot to perform puzzle-solving actions, if supported by the hardware.
